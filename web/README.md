# یٰسین دواخانہ دُنیا پور

Urdu website + admin panel (Next.js).

## چلائیں

```bash
cd web
npm install
npm run db:setup
npm run dev
```

کھولیں: http://localhost:3000

## ایڈمن

- URL: http://localhost:3000/admin/login
- ای میل: `admin@yasindawakhana.com`
- پاس ورڈ: `YasinAdmin123!`

پاس ورڈ `.env` میں `ADMIN_PASSWORD` سے بدل کر `npm run db:seed` چلائیں۔

## کیا شامل ہے

- اردو نستعلیق فونٹ، RTL
- ۱۷ ہربل ادویات (تصویر + تفصیل؛ قیمت ایڈمن سے)
- کتب، بلاگ / طبی مشورے
- فرنٹ پیج: بزرگ + نیو آفرز
- واٹس ایپ 0301-4185965 اور 0344-7014392
- مکمل ایڈمن: تصاویر، قیمت، آفر، مضمون، دوا، کتاب
